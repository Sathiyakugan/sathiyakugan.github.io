This package is designed to help users easily set up a standard folder structure for machine learning and deep learning projects.

`mlskeleton` aims to make it easy for users to set up a consistent and organized folder structure for their projects. It includes a range of common folders and files that you might need for your project, such as data folders, model files, Jupyter notebooks, and source code files.
